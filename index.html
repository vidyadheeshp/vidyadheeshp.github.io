Vāk — a language and its compiler

Independent project

A compiler project I built on my own time: a programming language whose entire front end — lexer, parser, semantic analyser, bytecode compiler and virtual machine — is written in the language itself. Its type system encodes the kāraka roles of Pāṇini's grammar, so a function declares what part each argument plays in the action rather than relying on position, and argument order stops mattering.

वाक् Vāk

Self-hosting, with five execution engines held to byte-identical output.

# संग्रहः is the अपादानम् — the source we draw from.
# परीक्षा is the करणम् — the means by which.
कार्यम् छानय(अपादानम् सूची संग्रहः, करणम् कार्यम् परीक्षा) : सूची {
    सूची फलम् = []।
    प्रत्येकम् (अङ्गम् अन्तः संग्रहः) {
        यदि (परीक्षा(अङ्गम्)) { योजय(फलम्, अङ्गम्)। }
    }
    प्रत्यागच्छ फलम्।
}

# The same call three ways — order is free because the roles are marked.
मुद्रय छानय(अङ्काः, समः)।
मुद्रय छानय(अपादानम्: अङ्काः, करणम्: समः)।
मुद्रय छानय(करणम्: समः, अपादानम्: अङ्काः)।
Run it in your browser → About the language The manual Source

A Vāk program runs on five engines — a tree-walking interpreter, a bytecode virtual machine, that machine rewritten in Vāk, a machine in C, and the whole self-hosted toolchain compiled to a native executable. All five are held to byte-identical output on every example, which is what keeps the self-hosting claim testable rather than rhetorical. The playground linked above is that same toolchain compiled to WebAssembly: it lexes, parses, analyses, compiles and runs Vāk inside the browser, with no server involved.

It has turned out to be a useful teaching language as well. A student who can read the keywords can often guess what a program does before anyone explains the syntax.

About

I hold an MTech in Software Engineering from Manipal Institute of Technology and a BE in Information Science & Engineering from Tontadarya College of Engineering, Gadag (VTU). I have been teaching at KLS Gogte Institute of Technology since 2017, and leading its IT Cell since 2019.

What I care about in both halves of the job is the same thing: the moment a student stops copying syntax and starts seeing how a language actually works, and the moment a piece of software stops being a demo and starts being the thing an office uses every day. Most of the systems listed above began as a process somebody was running on paper.

Outside that I read Indian philosophy, particularly Dvaita epistemology and tarka, the classical logic tradition. That reading is what led to Vāk: Pāṇini's Aṣṭādhyāyī is a formal grammar with rule ordering and metarules, written twenty-five centuries before anyone spoke of parsers, and I wanted to find out what it costs to actually compile it rather than just cite it. In August 2025 I helped establish the Centre for Sanskrit Learning at Gogte Institute of Technology in collaboration with Central Sanskrit University, Delhi.
