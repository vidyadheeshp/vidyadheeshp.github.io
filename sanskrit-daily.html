The idea

Most people who start Sanskrit stall, not because it is too hard but because the usual entry points ask for too much: a textbook, a course, a fixed hour. Sanskrit Daily takes the opposite approach. Each day there is one new, small lesson — short enough to finish over a cup of tea — and the habit of returning does the work.

It grew out of my teaching and out of my interest in Sanskrit grammar, which also led to Vāk, and from my involvement with the Centre for Sanskrit Learning at KLS Gogte Institute of Technology.

What it offers

  • A new lesson every day. Bite-sized, so it fits into any routine.
  • Interactive. The lessons are run in the browser rather than being static pages.
  • Free, with no login. Open the page and start; there is no account to create.
  • No tracking, no ads. Nothing in the app is there to monetise the learner.
  • Installable. It is a progressive web app, so it can be added to a phone or desktop and used like any other app.

How it is built

Sanskrit Daily is a single-page web application, built with Vite and hosted as static files on GitHub Pages, so there is no server behind it. A service worker and web app manifest make it installable. Because the site is static and does not ask for accounts, there is no learner data to collect or lose.

Who it is for

Anyone curious about Sanskrit — students, programmers who have heard that Pāṇini's grammar is a formal system, and people returning to a language they once studied. If you would like to use it with a class, or have suggestions for lessons, write to me at vidyadheeshp@gmail.com.
